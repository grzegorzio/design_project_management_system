# Функциональные требования

> Источник: раздел 1.5 ВКР — сформированы на основе анализа бизнес-процессов дизайнерской компании (AS-IS) и опроса 42 специалистов отрасли (дизайнеры, арт-директора, руководители проектов), март 2026.

## User stories

- Как руководитель проекта, я хочу создавать проекты, этапы и задачи, чтобы управлять всей проектной структурой и контролировать сроки.
- Как руководитель проекта, я хочу видеть диаграмму Ганта и календарь задач, чтобы планировать ресурсы и дедлайны.
- Как дизайнер, я хочу загружать файлы с версионностью, чтобы сохранять историю изменений и не терять актуальные макеты.
- Как арт-директор, я хочу устанавливать статусы согласования макетов («На согласовании», «Утверждено», «Требует правок»), чтобы отслеживать прогресс и вносить правки.
- Как руководитель проекта, я хочу учитывать время и ресурсы сотрудников через тайм-трекер, чтобы контролировать загрузку и перерасход бюджета.
- Как аналитик, я хочу формировать отчёты по проектам, сотрудникам и бюджету, чтобы анализировать эффективность работы команды.
- Как клиент, я хочу видеть статус проекта по этапам, чтобы понимать текущий прогресс выполнения работ.
- Как клиент, я хочу иметь доступ к срокам выполнения задач и этапов проекта, чтобы контролировать соблюдение дедлайнов.
- Как клиент, я хочу получать финальные материалы проекта через систему, чтобы иметь централизованный доступ ко всем результатам работы.

## Приоритизация (MoSCoW)

| Категория | Требование |
|---|---|
| **Must have** | Создание и управление проектами, задачами и этапами |
| | Согласование макетов |
| | Ролевая модель и разграничение прав доступа |
| | Хранение данных в централизованной системе |
| | Просмотр статуса проекта клиентом |
| | Тайм-трекинг и учёт трудозатрат |
| **Should have** | Диаграмма Ганта и календарь задач |
| | Формирование отчётности |
| | Версионность файлов |
| **Could have** | Автоматические рекомендации по загрузке сотрудников |
| | Расширенная аналитика и визуализация данных |

## Ключевые проблемы, которые решает система (из опроса, n=42)

| Проблема | Данные опроса |
|---|---|
| Сложности согласования макетов | 24,8% отметили как основную проблему; у 33,3% сроки растут на 10–20%, у 16,7% — на 20–30%, у 11,9% — более чем на 30% |
| Фрагментированность коммуникаций | 81% — нет единой истории взаимодействия; 57,1% тратят 25–40% времени на доп. коммуникацию |
| Неравномерная загрузка сотрудников | 57,2% отмечают снижение производительности не менее чем на 20% при перегрузе |
| Проблемы с файлами | 28,6% сталкиваются с проблемами версионности; 42,9% иногда выполняют повторную работу из-за устаревших файлов |
| Отсутствие учёта времени | 14,9% отметили отсутствие системного учёта трудозатрат |

90,5% опрошенных подтвердили необходимость внедрения единой системы управления проектами.
